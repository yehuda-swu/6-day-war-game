# Six Days of Decisions — V16 changelog

## Main updates
- Home screen simplified and repositioned around a cleaner war-room mission feel
- Start button now always shows **Start Mission**
- Removed saved-progress behaviour; each session begins fresh
- Added a background music toggle and procedural ambient soundtrack
- Simplified several pieces of on-screen wording for a younger audience

## Historical media updates
- **Jerusalem under fire** now uses the local Jerusalem archive photo on the decision card and plays the shelling footage after the choice
- **A divided Jerusalem** now uses the supplied divided-Jerusalem aerial image on the decision card
- Rebuilt the **Jerusalem animated map** with an Old City visual marker, Dome of the Rock icon and city-wall graphic
- Added a new **Golan animated map** showing IDF movement up the Heights and Syrian withdrawal eastwards towards Damascus
- Final screen now includes:
  - before/after maps of Israel
  - Western Wall celebration photos
  - tightened discussion prompts

## Note
- A dedicated King Hussein archive photo was requested for the Jerusalem under fire decision card. This build uses a Jerusalem front archival image already in the package, so the sequence works immediately. If a preferred King Hussein photo is supplied later, it can be swapped in quickly.
