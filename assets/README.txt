For a map instead of a photo, save it with the relevant filename.

For a video, add a video in this folder (for example 08-old-city.mp4)
and then edit the relevant stage in game.js so the video field is:
video:'assets/08-old-city.mp4'

Images should be landscape format, ideally at least 1200px wide.
Use only media you have permission to publish.
Keep images smaller than around 2 MB when possible.

The schematic map in the game is already included in index.html.
No map upload is necessary for the first version.
