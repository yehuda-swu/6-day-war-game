# Version 19: Clear outcome viewing

The historical video or animated map is now shown in a dedicated media frame with **no text covering it**.

* Desktop: wide media panel on the left, short outcome and controls on the right.
* Mobile and tablet: media first, outcome and controls below.
* All moving images are fitted within their frames without cropping.
* A fullscreen expand button is available for videos and maps.
* The archival photograph reveal after Operation Focus stays inside the media frame.
* The existing original music, Jerusalem audio, historical credits and lives system are retained.

### Test results

Local browser tests confirmed no overlap at 1440x900 and 390x844, no horizontal overflow, no JavaScript errors, Next Decision, replay, home, restart, Start Mission and fullscreen.
